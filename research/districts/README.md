# District profiles

Each profile tests the claim *"rising benefit costs are forcing cuts, layoffs and larger class sizes"* against district budget presentations, board minutes and local news (researched 2026-10-24), alongside our computed numbers.

**Classification key:** **Confirmed**: the district explicitly ties cuts to benefit/health costs. **Consistent**: cuts happened and benefits are one stated factor. **No cuts reported**: the district absorbed the increase (usually via the levy cap's health-care adjustment, state aid, or reserves). **Insufficient evidence**: no usable public documents found.
